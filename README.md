### 멤버 , 영화 , 예약 , 상영 , 상영관은 각각 고유한 id 를 갖는다.

데이터베이스의 관점에서 볼 때 관계를 구성

### 1. 영화

한 영화는 여러 상영을 할 수 있음
영화와 상영은 1:N 관계

### 2. 상영관

상영관은 여러 상영을 할 수 있음
상영관과 상영은 1:N 관계

### 3. 멤버

멤버는 여러 예매를 할 수 있음
멤버와 예약은 1:N 관계

### 4. 상영

상영 정보는 여러 예매와 연결됨
상영과 예약은 1:N 관계

### 따라서 각각의 객체는 자신만의 고유한 id 를 가지고있고 관계를 맺는 foreign key 를 가짐으로써 서로의 관계를 식별한다.


## 구현해야할 기능

1. 각각 객체 클래스를 생성 및 고유 키와 외래 키 속성 부여
2. 데이터 베이스 확장 가능성을 위한 인터페이스 저장소 및 Memory 상을 통한 구현
3. 할인 정책 구현
4. 예약 서비스 구현
5. 결제 서비스 구현
6. 사용자를 위한 주문 서비스 구현
